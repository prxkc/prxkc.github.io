# Typography

Version 3 is set in Inter, self-hosted through @fontsource-variable/inter under SIL OFL 1.1. Only the upright Latin file ships (weights 100–900); the design takes its hierarchy from weight and tone, so it needs no italic. The license is in public/licenses/Inter-OFL.txt.

Sizes: body 13px (13.5px from 1200px, 14.5px from 1600px) and captions 11.5px (12px, then 12.5px). Titles use the body size at weight 500. Inter's single-storey a (`cv11`) keeps it soft.

Crimson Pro, used by v2, is still available from the v2 tag. Old ignored trial files are unused and excluded from production builds.
